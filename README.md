# health-tracker# 💪 Трекер здоровья (Health Tracker)

## 📌 Описание проекта
Это простое веб-приложение для отслеживания здоровья.  
Пользователь может записывать количество выпитой воды и тренировки, а также смотреть статистику.

---

## 🎯 Проблема
Люди часто не следят за:
- количеством воды в день  
- физической активностью  

---

## 💡 Решение
Приложение помогает:
- фиксировать выпитую воду 💧  
- записывать тренировки 🏋️  
- смотреть общую статистику 📊  

---

## ⚙️ Функции
1. Добавление воды  
2. Добавление тренировок  
3. Просмотр статистики  
4. Встроенная презентация проекта  

---

## 🛠 Технологии
- Python 3.10+
- Streamlit
- JSON (для хранения данных)
